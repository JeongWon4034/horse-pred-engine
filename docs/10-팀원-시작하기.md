## 3. 자주 쓰는 명령

```bash
# 학습 — kind 는 linear | embed | history | attn
PYTHONUTF8=1 uv run python -m model.train history
PYTHONUTF8=1 uv run python -m model.train history --hist-len 20 --seed 1 --tag _L20_s1
PYTHONUTF8=1 uv run python -m model.train history --market      # 77피처(배당 포함)

# 전 단계 무인 실행
bash run_stages.sh

# 분해표 — 혼전도·등급·거리·두수별로 어디서 이기는지
PYTHONUTF8=1 uv run python -m model.breakdown lgb_73 history_73

# 저장된 가중치로 다른 분할 점수 (재학습 없음)
PYTHONUTF8=1 uv run python -m model.score --split game --lgb --ckpt history_73_L20_s1

# 단승 수익률 백테스트
PYTHONUTF8=1 uv run python -m model.backtest --pred ../experiments/pred/history_73_L20_s1_game.parquet
```

**마사회 API 로 새 경주를 받으려면** 키가 필요합니다. 정원에게 받거나
[공공데이터포털](https://www.data.go.kr/data/15063979/openapi.do)에서 발급받아
`pipeline/.env` 에 넣습니다.

```
KRA_API_KEY_ENCODED=발급받은키
```

```bash
PYTHONUTF8=1 uv run python -m ingest.ledger              # 원장 전량 (8분)
PYTHONUTF8=1 uv run python -m ingest.ledger --date 20260912   # 하루만 추가
```

## 4. 규칙 — 깨면 비교가 무효

| # | 규칙 | 이유 |
|---|---|---|
| 1 | **`game` 분할로 학습·튜닝 금지** | 유저가 플레이할 경주. 학습에 쓰면 답을 아는 AI 와 대결하게 됨 |
| 2 | **`test` 는 최종 1회** | 지금까지 안 열었습니다. 열려면 먼저 상의 |
| 3 | **셔플 금지** | 같은 경주 말들이 붙어 있어야 함. 섞으면 에러 없이 조용히 틀린 모델이 나옴 |
| 4 | **말 ID(`hrNo`)를 입력에 넣지 않음** | 과거 전적을 찾는 열쇠로만 사용 |
| 5 | **비교는 valid 로** | test 를 보면서 튜닝하면 그 숫자도 낙관적으로 치우침 |
| 6 | **채점은 팀 하네스로** | `C.report()`. 자체 평가기를 만들면 LightGBM 과 비교가 안 됨 |

| 장부 | 무엇을 적나 |
|---|---|
| `experiments/ledger.md` | 본 실험 (S1~S5 계획 안의 것) |

적을 것: 날짜 · 커밋 · **데이터 기준 커밋** · 모델 · 피처 수 · seed · top-1 · top-3 · logloss · 메모.

> 계획 밖 실험은 **별도 브랜치 · 새 파일 · 별도 장부**로. 기존 코드를 고치지 마세요.

## 9. 첫 작업으로 좋은 것

바로 손댈 수 있고 결과가 명확한 것들입니다.

| # | 할 일 | 왜 필요 | 소요 |
|---|---|---|---|
| 1 | **이력 길이 L=0 측정** — 시퀀스 없이 돌려서 순수 기여분 재기 | "딥러닝이어야 하는 이유"의 핵심 숫자인데 비어 있음 | 1시간 |
| 2 | **F1 ablation 을 seed 3개로** 재측정 | 지금은 seed 1개라 근거가 약함 | 1시간 |
| 3 | **3착 확률 보정** — 검증셋으로 스칼라 하나 맞추기 | 강한 말을 9%p 과대평가 중 | 2시간 |
| 4 | **2004 확장 데이터로 S3 재측정** | 건모님이 "각자 돌려봐 달라"고 요청 | 2시간 |
| 5 | **다음 주말 사전 예측** | 결과 나오기 전 공개하면 가장 강한 증거 | 반나절 |

1번과 2번이 제일 급합니다. 컨설턴트 피드백에 직접 답하는 숫자입니다.
