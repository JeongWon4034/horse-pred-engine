# 모델 파트 진행 현황 (이정원)

> 2026-09-07 기준. 서로 진행 상황을 모르니 여기 적어둡니다.
> 코드·실험은 개인 레포 `horse-pred-engine`, 익은 것만 팀 레포로 옮깁니다.

## 한눈에

| 항목 | 상태 | 비고 |
|---|---|---|
| 팀 LightGBM 재현 | 완료 | 팀 표와 ±0.05 일치 |
| 딥러닝 4단계 (S1~S4) | 완료 | 같은 채점기로 전부 측정 |
| 모델 채택 | 완료 | S3(전적 GRU) + LightGBM 앙상블 |
| 6축 슬라이더 모델 (S5) | 1차 완료 | 개선안 남음 |
| 게임 ROI 백테스트 | 완료 | **부풀려짐 확인 — 아래 공유사항 참조** |
| 실경기 예측 | 완료 | 지난 주말 49경주, 답 안 보고 |
| test 최종 평가 | **미개봉** | 튜닝 여지 남겨둠 |

## 결과 — valid 1,254경주 (배당 없는 조건 = 73피처)

넘어야 할 선: LightGBM 34.0 + 오차 2배 = **35.7**

| 모델 | 1등 적중 | 3착 이내 | 확률 품질 | LGB 대비 |
|---|---:|---:|---:|---|
| 시장 (인기 1위마, 참고) | 39.3% | 69.3% | — | — |
| LightGBM 73 (기준) | 34.0% | 63.2% | 1.885 | — |
| S1 선형 | 33.6% | 64.0% | 1.902 | −0.4 |
| S2 임베딩 | 34.0% | 64.0% | 1.885 | +0.0 |
| **S3 전적 GRU** | **34.8%** | 64.3% | **1.846** | +0.8 |
| S4 어텐션 | 34.4% | 63.0% | 1.902 | +0.5 |
| S3 + LGB 앙상블 | 35.3% | 64.0% | 1.852 | +1.4 |

**판정**

| 질문 | 답 |
|---|---|
| 적중률로 LightGBM을 이겼나 | **아니오.** 선 35.7 미달, 모든 차이가 오차 안 |
| 그럼 딥러닝은 쓸모없나 | **아니오.** 확률 품질에서 10번 중 10번 우위 |
| 어느 단계가 효과 있었나 | S3만. 말의 과거를 평균 내지 않고 순서대로 읽는 것 |
| S4 어텐션은 | 채택 안 함. 3.6만 경주로는 과적합 |
| 홍보 숫자는 | 35.3이 아니라 **34.8**. 35.3은 valid로 고른 낙관값 |

## 실경기 예측 (2026-09-07, 신규)

지난 주말 49경주를 **답 안 보고** 예측했습니다. 팀 데이터셋에 없는 진짜 새 경주입니다.

| 모델 | 1등 적중 | 3착 이내 |
|---|---:|---:|
| 시장 (인기 1위마) | 42.9% | 73.5% |
| **우리 딥러닝 (S3)** | **32.7%** | 63.3% |
| LightGBM 73 | 26.5% | 61.2% |

오차 ±6.8%p (49경주라 정밀하지 않음)

| 읽기 | 내용 |
|---|---|
| 성능 유지되나 | 예. valid 34.8 → 실경기 32.7, 오차 안 |
| LightGBM 대비 | +6.2%p 앞섬 |
| 시장 대비 | 10%p 뒤짐. 배당을 안 보는 조건이라 예상된 결과 |
| 1등 못 맞혀도 | 우리가 찍은 말이 **3착 이내에 69.4%** 들어감 (시장 75.5%) |

## 팀에 공유할 것 (중요)

| # | 내용 | 영향 |
|---|---|---|
| 1 | **게임 ROI는 부풀려져 있습니다.** game 경주가 학습 데이터 사이사이에 끼어 있어 AI가 그 시기를 이미 봤습니다. game에서 +0.5%인데 시간상 뒤인 valid에서 재면 −8.6%입니다. | 온보딩 "AI 수익률" 표기는 game 값이 아니라 **valid 값**으로. 인기마보다 8%p 덜 잃는 수준이고 이익은 아닙니다 |
| 2 | **경주 안에서 모두 같은 값인 항목 8개는 슬라이더에 올리면 안 됩니다.** 거리·두수·등급·함수율·날씨·월·선행마수·혼전도. 가중치를 올려도 순위가 안 바뀝니다 | UI 설계 |
| 3 | **슬라이더 모델(6축)은 정확도가 2.3%p 낮습니다.** 인기도 축이 너무 세서 6과목을 균등하게 나누면 희석됩니다. 기본 비중을 인기도 쪽에 실으면 회복됩니다 | 슬라이더 기본값 설계 |
| 4 | 조교 데이터(포털 15058782)는 우리 모델에 **없어도 됩니다.** 빼고 재봐도 적중률 차이 0.00%p. 전적 GRU가 그 정보를 이미 읽습니다 | API 신청 우선순위 |
