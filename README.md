## 확정된 것 한눈에

```
베팅은 과거 경기만 ○   → 데이터 3분할 필수 (모델 누수 차단)
주말 실경기 ○          → 예측 리포트 전용, 베팅 없음
피처 개별 ON/OFF ✕     → 축 가중치 ○
LightGBM ✕             → 랭킹 손실 + 신경망
전체 순위 학습 ✕        → top-3 ○
적중률 대표지표 ✕       → ROI ○
GNN ✕                  (데이터 규모상 과함)
미니게임 ✕             앱 성격 흐림
경마머니 환금성 ✕       법적 리스크 제거
베팅 7종 ○             → 몬테카를로 필수 확정
LangGraph = 조연 ○     주연은 직접 학습시키는 랭킹 모델
```

## 열려 있는 논점

- **55개 항목 vs 6축** — 설계서는 마패식 55개. 우리 차별점은 6축으로 묶는 것 ([01-기획.md](01-기획.md) 하단)
- **과거 경기 베팅의 대외 설득력** — 3분할이 그 답. 게임용 구획은 모델이 학습에서 못 본 경기여야 함
