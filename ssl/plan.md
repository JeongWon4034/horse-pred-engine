# ssl/ — 라벨 없이 먼저 배우고, 랭킹은 나중에 (김민지)

> 초안 2026-09-11. 팀 레포 `docs/model/plan_dl_minji.md`(결합확률) 와 별개 축이다. 그쪽은 "조합확률 공식"을
> 고쳤고, 이쪽은 정원 축이 멈춘 자리 — **"73피처로 top-1 을 LightGBM 보다 올릴 수 있나"** — 를 다른 길로 다시 간다.
> `pipeline/` 코드는 고치지 않는다. 데이터·채점은 `pipeline/data` 사본과 `model.team.C` 한 창구.
> 사전학습 모델을 밖에서 가져오지 않는다. torch 로 0 부터.

---

## 1. 한 줄

정원 축의 결론은 *"구조를 키워서는 안 오른다. 더 얻으려면 데이터 양"* 이었다.
건모는 학습 구간을 2004년까지 늘린 데이터셋(`docs/dataset-2004ext`, train +40%)을 만들었는데
LightGBM 에서는 효과가 없었고, **"다른 모델링에서는 다르게 나올 수 있으니 각자 돌려봐 달라"** 고 남겼다.

두 결론을 합치면 아직 아무도 안 해본 칸이 하나 남는다:

**착순 라벨 없이 54만 행에서 말·경주의 표현을 먼저 배우고(자기지도), 그 위에 랭킹 헤드만 얹는다.**

정원의 S1~S4 는 전부 착순으로만 학습했다. 12두 경주 한 판에서 라벨이 주는 정보는 순열 하나뿐이고,
피처 73개 × 12두 = 876개 숫자의 구조는 버려진다. 그걸 먼저 쓰자는 것이다.

## 2. 왜 이 축인가 — 근거

### 2.1 정원 축이 남긴 사실 셋

| 사실 | 출처 | 이 계획에서의 뜻 |
|---|---|---|
| 몸통을 153 → 41만 파라미터로 키워도 top-1 이 안 오른다 | `result_dl.md` §2, `08-모델-작업정리.md` | 구조는 답이 아니다. **학습 신호**를 바꿔야 한다 |
| F1 집계 피처 17개를 다 빼고 GRU 이력만 남겨도 성능이 같다 (35.0 → 35.1) | `ledger.md` ablation, `09-딥러닝-티가-안난다.md` §2 | 네트워크가 사람이 만든 피처를 **스스로 대체할 수 있다**. 그 능력을 라벨 없이 키우면? |
| 이력 길이 L=0 대비 시퀀스는 top-1 에 기여하지 않는다 | PR #9 `exp/hist-len-curve` | 시퀀스 모델링 자체가 아니라 **표현 학습**이 남은 여지다 |

### 2.2 건모가 남긴 데이터

`docs/dataset-2004ext/` — 스키마·분할·valid·test·game 이 `docs/dataset` 과 **완전히 같고 train 만 2004년부터**.

```
train   385,514행 36,586경주  →  538,898행 51,476경주   (+39.8%)
valid / test / game   변화 없음 (race_id 집합 동일)
```

LightGBM lambdarank 에서는 차이가 없었다(건모 측정). **같은 자로 재도 비교가 성립하는 데이터가
이미 있는데 아무도 안 썼다.** 이 계획의 사전학습 풀이 정확히 이것이다.

### 2.3 자기지도가 표 데이터에서 통한 선례

| 방법 | 핵심 | 여기서 쓸 부분 |
|---|---|---|
| VIME (2020) | 피처 일부를 가리고 복원 + 어느 칸이 가려졌는지 맞히기 | 마스크 복원 손실 |
| SCARF (2022) | 행의 일부 피처를 다른 행 값으로 바꿔 "손상본"을 만들고, 원본과 손상본이 같은 행임을 대조학습 | 대조 손실. 구현이 단순하고 표 데이터에서 안정적 |
| SAINT (2021) | 행 간 attention + 대조 사전학습 | 경주 안 말들끼리의 대조로 응용 |

이 셋은 전부 "라벨이 적을 때 GBDT 와의 격차를 줄인다"가 결론이다. 우리는 라벨이 적은 게 아니라
**라벨이 주는 정보가 적다**(경주당 순열 하나)는 점이 다르다. 그래서 통할지는 실험으로만 안다.

### 2.4 정직하게 — 사전확률은 낮다

시장 39.3, 펀더멘털 73피처 천장이 ~35 근처라는 증거가 강하다. 정원의 18구성 격자, 나의 20구성 격자
모두 "튜닝 부족이 아니다". 이 계획도 **실패할 가능성이 더 높다.** 그래서 §5 단계마다 중단 기준을
먼저 적고, 결과가 나빠도 장부에 그대로 적는다. 실패해도 "자기지도까지 해봤고 안 됐다"는
정원 결론(데이터 양)에 대한 반례 또는 보강이 된다.

## 3. 정원·건모와 무엇이 다른가

| | 이정원 S3 | 이건모 basemodel | **이 계획** |
|---|---|---|---|
| 학습 신호 | 착순 (PL top-k) | 착순 (PL) | **① 피처 자체 (마스크·대조) → ② 착순** |
| 데이터 | train 2010~ | train 2010~ | **2004ext train 54만 행** (①·② 모두) |
| 입력 | 73피처 + 이력 텐서 | 73피처 → 6축 타워 | 73피처 (이력 없음 — PR #9 근거) |
| 몸통 | 임베딩 + GRU | 축별 MLP | **피처 토큰 Transformer (FT-Transformer)** 또는 MLP — 소형 |
| 새로움 | 순서를 읽는다 | 시장을 프리셋 상수로 뺀다 | **라벨 없이 배운 표현이 손피처를 대체하는가** |

정원 코드(`horse-pred-engine/pipeline/model/*`)는 손대지 않는다. 손실·배치·평가는 개념만 가져와
새 파일에 다시 쓴다.

## 4. 고정 — 바꾸면 비교가 깨진다

| 항목 | 규칙 |
|---|---|
| 데이터 | `common.load(split)`. 사전학습 풀은 **2004ext `train` 만** — game·valid·test 행은 라벨 없이도 넣지 않는다. 자기지도라도 "본 것"은 본 것이다 |
| 데이터 기준 커밋 | `05d8230` (clean 적용 후). 정원 재측정(PR #11)과 같은 커밋 |

| 채점 | `common.report()` / `evaluate()`. logloss·CI 는 정원 `evaluate.py` 식 그대로 재구현 |
| 비교 분할 | valid 1,254경주. test 안 연다 |
| 금지 입력 | `y_*` · `hrNo` · `hrName` · tier P |
| 정렬 | race_id 블록 유지. 경주끼리만 셔플 |
| seed | 단계당 **5회**. 평균 ± 편차 |
| 넘어야 할 선 | 새 커밋 LGB73 = **33.49** (정원 09-09 재측정). 33.5 + 2×0.85 = **35.2** 이상일 때만 "이겼다". 미만은 "차이 없음" |

**2004ext 주의 두 가지 (README §4·§5 참고)**
- 2004~2009 는 육종가(F2_ebv_*) 가 전부 결측이다. 결측 지시자로 들어간다 — 사전학습이 "결측 패턴"을 배우는 것도 괜찮다

## 5. 단계

| 단계 | 내용 | 라벨 | 파라미터 | 중단 기준 |
|---|---|---|---|---|
| **P0** | 사전학습 없는 같은 몸통 (대조군) | 착순 | ~60k | — (기준점) |
| **P1** | 마스크 복원 사전학습 → 랭킹 미세조정 | ①없음 ②착순 | ~60k | P0 대비 CI 가 0 을 품고 logloss 도 안 내려가면 **P2 로 가되 기대치 낮춤** |
| **P2** | 대조 사전학습(SCARF) → 미세조정 | ①없음 ②착순 | ~60k | P1·P2 둘 다 P0 와 차이 없음 → **§7 로 종료** |
| **P3** | 사전학습 풀 통제: 2010~ vs 2004~ / 연도 입력 유무 | | | 2004 추가분이 기여 안 하면 "데이터 양" 가설 기각 |
| **P4** | 손피처 대체 검증: F1 집계 17개 제거(56피처)로 미세조정 | 착순 | | 73 과 같으면 정원 ablation 재현 = 딥러닝 근거 강화 |
| P5 (여유) | 경주 안 대조 — 같은 경주 말들을 negative 로 | | ~120k | |

### P0 — 대조군을 먼저 만든다

사전학습 효과를 재려면 **같은 몸통을 랜덤 초기화로 착순만 학습한 것**이 있어야 한다.
정원 S1/S2 를 가져다 쓰면 몸통이 달라 비교가 안 된다.

```python
class Body(nn.Module):
    """73피처 → d 차원 표현. 연속형은 선형 토큰, 범주형은 임베딩 토큰 → 소형 Transformer 2층.
    FT-Transformer 를 축소한 것. 이 몸통을 P0~P4 가 전부 공유한다."""
    def __init__(self, n_num, cat_cards, d=64, layers=2):
        ...
    def forward(self, x_num, x_cat) -> Tensor[n_rows, d]

class RankHead(nn.Module):
    def __init__(self, d): self.fc = nn.Linear(d, 1)
```

손실은 정원과 같은 Plackett-Luce top-5. 최고 epoch 는 valid logloss 로 고른다
(PR #12 §6-1 · 건모 `--select logloss` 와 같은 규칙 — top-1 로 고르면 ep1 이 뽑히는 문제).

**P0 통과 기준: 정원 S2(34.02 ±0.41) 근처.** 여기서 크게 뒤지면 몸통 문제라 사전학습 이전에 고친다.

### P1 — 마스크 복원

```
행 하나 x (73칸) → 칸의 30% 를 무작위로 가림 → Body → 두 헤드
  · 복원 헤드: 가린 연속형 값 회귀(MSE, z-score 단위) + 가린 범주형 분류(CE)
  · 마스크 헤드: 각 칸이 가려졌는지 (BCE)          ← VIME
```

54만 행, epoch 당 CPU 1~2분 예상. 20 epoch 후 Body 가중치를 저장하고 P0 와 같은 절차로 미세조정.
미세조정은 두 방식 다 잰다 — (a) Body 동결 + 헤드만, (b) 전체 미세조정(lr 1/10).
(a) 가 P0 에 근접하면 "표현 자체가 순위 정보를 담았다"는 강한 증거다.

### P2 — 대조 (SCARF)

```
행 x → 손상본 x': 칸의 60% 를 같은 컬럼의 다른 행 값으로 교체
Body(x), Body(x') 를 projection 후 InfoNCE. 배치 안 다른 행이 negative.
```

배치는 **경주 단위**로 만든다 (같은 경주 12두가 한 배치에). 그러면 negative 의 절반이
"같은 경주의 다른 말"이 되어 경주 내 상대비교를 저절로 배운다 — P5 의 약식 버전.

### P3 — 무엇이 기여했나 (통제)

| 조건 | 사전학습 풀 | 미세조정 | 묻는 것 |
|---|---|---|---|
| P3-a | 2010~ (38만) | 2010~ | 사전학습 자체의 효과 |
| P3-b | **2004~ (54만)** | 2010~ | 라벨 없는 옛 데이터의 효과 |
| P3-c | 2004~ | 2004~ | 라벨 있는 옛 데이터까지 (건모 LGB 조건과 대응) |
| P3-d | 2004~, 연도 입력 | 2010~ | 드리프트를 명시하면 나아지나 |

P1/P2 중 나은 쪽 하나로만 돈다. 4조건 × seed 5.

### P4 — 손피처 대체

정원 09 문서의 핵심 근거("F1 집계 17개를 빼도 같다")를 이 몸통에서 재현한다.
사전학습된 Body 로 56피처 미세조정 ≈ 73피처면, **"라벨 없이 배운 표현이 사람 피처를 대체한다"**
가 되고, 이것이 "딥러닝 티가 안 난다"에 대한 가장 직접적인 답이다.
