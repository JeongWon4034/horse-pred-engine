(`ingest/ledger.py`, `build_live.sh`). 학습은 하지 않았다 — **이미 학습된 S3 체크포인트를 그대로 썼다.**

- 목적: 팀 데이터셋에 없는 **진짜 새 경주**를 답 안 보고 예측해 적중률을 재는 것
- 모델: `experiments/runs/history_73_L20_s{20260901,1,2,3,4}.pt` (S3 L=20, seed 5개 확률 평균) + LightGBM 73

## 2. 성적표 재빌드 (`build_live.sh`)

팀 빌더(`docs/dataset/build_v2.py`)를 우리 원장으로 돌렸다. 피처 정의를 새로 짜면 학습 조건과
어긋나므로 **팀 코드를 그대로 쓰는 것이 유일하게 안전한 길**이다.

패치 2개 (둘 다 조건 맞추기, 개선 아님) — 이유는 `build_live.sh` 머리말에 적었다.
① 분할 경계 날짜 고정 (안 하면 9월 경주가 test 로 빨려든다) ② 등급 정규화 해제 (원핫 어휘 보존)

**피처 대조 (valid 13,252행)**

공통 65개 중 **59개 완전 일치**. 어긋난 6개와 원인:

| 피처 | 일치율 | 원인 |
|---|---:|---|
| F1_tr_sessions_28d · F1_tr_jk_ridden_28d | 0.02% | 조교 API(`trcontihi`, 포털 15058782) 미승인 |
| F2_sire_prog_n · F2_sire_win_rate | 28% | 혈통 API8_2 는 **현역마 4,076두만** 준다 — 은퇴마 누락 |
| F2_sire_id | 78% | 위와 같음 |
| F5_style | 95% | 원인 미상. 결측 위치 차이로 보인다 |

육종가(F2_ebv_* 8개)·F2_inbreeding 은 재료가 없어 열 자체를 NaN 으로 채웠다.
학습 데이터에서도 63~86% 결측이던 항목이라 영향이 작다.

**예측 대상 `new` 분할**: 508행 51경주, 2026-08-31 ~ 09-06. 팀 데이터셋에 없는 행이다.
9월 출전마는 현역이라 혈통 결측 0.2%(학습 때 13.6%보다 오히려 좋음), 나머지도 학습 때와 비슷하다.

## 3. 조교 2칸을 빼면 얼마나 손해인가 (valid 대조 실험)

조교 API 승인을 기다리는 동안, **9월 경주는 손대지 않고** valid 로만 재봤다.
`F1_tr_sessions_28d` · `F1_tr_jk_ridden_28d` 를 NaN 으로 만들고 같은 체크포인트로 예측.

| valid 1,254경주 | top-1 | top-3 | logloss |
|---|---:|---:|---:|
| 조교 있음 | 34.77 | 64.27 | 1.8464 |
| 조교 비움 | 34.77 | 64.11 | 1.8441 |

**차이 +0.00%p [95% CI −0.96, +0.88], logloss 는 오히려 −0.0023.**

비움이 실제 반영됐는지 확인함: 두 열의 표준편차가 0 이 되고 입력 12,994칸이 바뀐다.
`train` 결측 0% 이라 `#na` 플래그 열은 없다 → 중앙값으로 채워진다.

**해석**: S1 선형에서 `F1_tr_sessions_28d` 는 153칸 중 중요도 4위(+0.205)였지만, S3 에서는 없어도
그만이다. 말별 직전 20출전 GRU 가 "조교를 많이 한 말은 최근 경주에서 좋았다"를 이미 읽는다.
`F1_tr_jk_ridden_28d` 는 S1 에서도 70위, 평균 0.4회라 원래 기여가 없다.

→ **조교 API 를 기다릴 필요가 없다.** 승인되면 넣어서 재확인하되 숫자는 거의 안 바뀔 것이다.

## 4. 결과 — 지난 주말 49경주 (답은 한 번만 봤다)

배당이 있는 49경주만 (51경주 중 2경주 제외 — 시장 비교 조건). **표준오차 ±6.8%p.**
이력 풀은 train+valid+test (~2026-08-30). 9월보다 과거이므로 누수 아니다. 평균 이력 11.1/20.

| | top-1 | top-3 | logloss |
|---|---:|---:|---:|
| 시장 (인기 1위마) | 42.9 | 73.5 | — |
| **S3 L20 seed5 평균** | **32.7** | 63.3 | 1.8799 |
| LightGBM 73 | 26.5 | 61.2 | 1.9640 |
| 앙상블 S3 0.8 + LGB 0.2 | 32.7 | 59.2 | 1.8778 |

**읽기**

- **valid 기대치가 재현됐다.** S3 valid 34.8 → 실경기 32.7. 차이가 오차(±6.8) 안이다.
  처음 보는 경주에서도 성능이 유지된다는 첫 실증.
- **LGB 대비 +6.2%p.** valid 의 +0.8%p 보다 크지만 49경주라 잡음일 수 있다.
- **시장에 10%p 졌다.** 73피처는 배당을 안 보는 조건이라 예상된 결과다.

**1등은 못 맞혀도 3착에는 든다**

우리가 1위로 찍은 말 49마리의 실제 착순: 1등 16 · 2등 9 · 3등 9 · 9등 이하 5. 평균 3.5등.

| | 1등 | 3착 이내 |
|---|---:|---:|
| 우리 1위마 | 32.7% | **69.4%** |
| 시장 1위마 | 42.9% | 75.5% |

연승식(3착 이내) 관점에서는 시장과 6%p 차이다. 단승(32.7 vs 42.9, 10%p)보다 격차가 작다.
본 장부의 "PL topk=3 은 top-3 만 올린다"와 방향이 같다 — 연승 상품이면 topk=3 학습이 후보다.

**시장과 다르게 고른 18경주에서 2번만 맞았다 (11.1%)**

같은 말을 고른 31경주는 45.2% 적중. 다르게 고른 18경주는 11.1%.
단 그 18경주는 시장 1위마도 7/18(38.9%)만 맞힌 **어려운 경주**였고, 우리 말도 11/18 은 3착에 들었다.
valid 1,254경주에서는 이 경향이 안 보였으므로 49경주의 잡음일 가능성이 높다. 다음 주말로 재확인.

**맞힌 사례 — 코리아컵 (09-06 서울 9R, Grade1)**

시장 1위 선데이펀데이(47.6%)가 2착, 모델이 45.7%로 1위로 본 딕테이언(시장 27.9%)이 1착.
