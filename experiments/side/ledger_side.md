## 1. game ROI — 학습된 모델로 game 3,700경주 점수 → 실배당 단승 1단위

`model.score --split game` 이 체크포인트(`experiments/runs/*.pt`)와 train 에서 다시 fit 한 전처리로 game 점수를 뽑는다.
이력은 train∪valid 풀에서 `rcDate < 경주일` 만 (game 행은 풀에 없음). LightGBM 은 같은 train 으로 재학습해 game 예측.

### 1-1. 결과 (전략 top1 = 매 경주 모델 1위마)

| 모델 | 베팅 | 적중 | ROI | 적중 평균배당 |
|---|---:|---:|---:|---:|
| 시장 (인기 1위마) | 3,687 | 37.3% | −20.7% | 2.12 |
| LightGBM 73 | 3,678 | 33.0% | −5.8% | 2.86 |
| LightGBM 77 (배당 포함) | 3,687 | 38.2% | −13.4% | 2.27 |
| S3 L10 단일 | 3,679 | 34.4% | −1.0% | 2.88 |
| S3 L10 seed5 평균 | 3,680 | 34.6% | −0.7% | 2.87 |
| S3 L20 seed5 평균 | 3,679 | 34.6% | **+0.5%** | 2.90 |
| LGB73 + S3 L20 (5:5) | 3,680 | 34.1% | −3.8% | 2.82 |

조건부 베팅(모델 확률 − 시장 확률 ≥ t 인 경주만): S3 L20 t=0.10 에서 1,136베팅 **+37.2%**, LGB t=0.10 +18.4%.
EV(확률×배당) 최대 말 베팅: S3 +19~26%, LGB −13%.

### 1-2. 이게 진짜인가 — 누수 점검

- **피처 누수 없음.** 첫 출전 말(F1_first_start=1)의 생애 성적이 game·valid·train 전부 NaN(현재 경주 결과 미포함). F1/F2/F3/F4 피처와 y_win 상관이 세 분할에서 동일(예: F1_win_rate_life +0.163/+0.166/+0.168).
- **적중률은 valid 와 같다.** LGB game 33.0% vs valid 34.0%, S3 34.6% vs 34.8%. 모델이 game 에서 더 잘 맞히는 게 아니다.
- **그런데 valid 에서 같은 전략을 재현하면 수익이 사라진다** (valid 에 배당 컬럼이 없어 `0.800/F6_mkt_prob` 로 역산 — game 에서 검증: 이 추정으로 시장 ROI −20.7% 정확히 재현):

| valid 1,254경주 | 적중 | ROI | 적중배당 |
|---|---:|---:|---:|
| 시장 | 39.3% | −16.6% | 2.12 |
| LightGBM 73 | 34.0% | −9.3% | 2.67 |
| S3 L20 seed5 평균 | 34.8% | −8.6% | 2.63 |
| LGB73 + S3 (5:5) | 35.3% | −7.7% | 2.61 |
| 조건부 t=0.03~0.10 (베팅 240~600) | 24~29% | −0.2 ~ +13.0% | 3.6~4.6 |

- **해석**: game 의 좋은 ROI 는 **시기 혼재** 때문이다. game 은 2015~24 개최일의 15% 를 뺀 것이고 train 은 그 사이사이 날짜를 전부 포함한다. 모델은 "그 시즌에 누가 잘 뛰었는지"를 이미 봤다(적중률은 같지만 배당 높은 말 쪽으로 정확히 기운다). valid(2025-11~2026-05, train 뒤)는 이 이점이 없다.
- **정직한 기대치는 valid 값이다**: 모델은 인기마보다 **8%p 덜 잃는다**. 매 경주 베팅으로 이익은 안 난다. 조건부 베팅은 손익분기 근처지만 베팅 수가 적어(±15%p) 확정 못 한다.
- **게임 서비스 관점**: 유저가 플레이하는 game 경주에서 AI 가 실제보다 강하게 보인다는 뜻. 온보딩 프리셋 ROI 표기는 game 값이 아니라 valid 값(또는 그 사이의 보수적 값)을 써야 한다. 이건 팀에 알릴 사항.

## 3. 앙상블 가중치 · seed 개수 (`model.side_ensemble`, valid)

### seed 개수 곡선 — S3 L20 확률 평균 (부분집합 전체 평균)

| seeds | top-1 | logloss |
|---:|---:|---:|
| 1 | 34.63 | 1.8605 |
| 2 | 34.39 | 1.8516 |
| 3 | 34.48 | 1.8487 |
| 4 | 34.63 | 1.8472 |
| 5 | 34.77 | 1.8464 |
| 10 (L20 5 + L10 5) | 34.45 | 1.8493 |

logloss 는 seed 를 더할수록 단조 개선(1.8605 → 1.8464). top-1 은 34.4~34.8 사이에서 안 움직인다 — **seed 평균은 확률 품질을 올리고 적중률은 못 올린다.** L10 을 섞으면 오히려 조금 나빠짐(L20 5개가 최선).

### 가중치 w·S3 + (1−w)·LGB

| w | top-1 | logloss | vs LGB top-1 (CI) |
|---:|---:|---:|---|
| 0.0 (LGB) | 33.97 | 1.8846 | — |
| 0.3 | 34.93 | 1.8616 | +0.96 [−0.08, +1.99] |
| 0.4 | 35.17 | 1.8562 | +1.20 [+0.00, +2.39] |
| **0.5** | **35.33** | 1.8519 | +1.36 [−0.08, +2.79] |
| 0.7 | 35.01 | 1.8465 | +1.04 [−0.64, +2.71] |
| 1.0 (S3) | 34.77 | **1.8464** | +0.80 [−1.20, +2.79] |

위 표는 valid 전체로 w 를 본 것이라 **낙관값**이다. 교차 적합(경주를 반으로 갈라 한쪽에서 logloss 최소 w 선택, 다른 쪽 측정, 20회):
- 선택되는 w 평균 **0.86** (0.7~1.0) — logloss 기준으로는 S3 비중이 커야 한다
- 홀드아웃 top-1 **34.76** vs 같은 홀드아웃 LGB 33.97 → **+0.79%p**, logloss 1.8466
- 즉 "35.3" 은 w=0.5 를 valid 에 맞춘 값이고, 정직하게 고르면 **+0.8%p 근처**가 기대치. 본 장부의 판정("차이 없음, logloss 우위")과 일치.

권고: 서비스 확률은 **S3 L20 seed5 평균 0.8 + LGB 0.2** 근처. top-1 홍보 숫자는 35.3 이 아니라 34.8 을 쓴다.
